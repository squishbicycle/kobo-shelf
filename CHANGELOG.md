# Changelog

What changed in each update, newest first.

## 2.1 (2026-10-25)
- **Tabs** for Books, My Words and Stats.
- **Sidebar** with all books, unread, reading, finished, plus your collections and series.
- **Multi-select** with batch actions (mark finished or unread, set series, collections, remove).
- **Collections:** create, rename and delete. They show up on the Kobo.
- **Series editing**, optionally numbering books in the order shown.
- **My Words:** words saved from the Kobo dictionary, with definitions from the Mac's dictionary (English) or `jdict` (Japanese). Export as CSV or as an Anki import file.
- **Stats:** total reading time, books finished, current reads with the Kobo's time-left estimate, and time per book.
- **Remove N previews…** clears Kobo's factory-loaded sample books, after backing up the database.
- New app icon.

## 2.0 (2026-10-25)
- First release: detects a plugged-in Kobo and shows every book in a cover grid with reading progress.
- Drag-and-drop adding, with EPUB → kepub conversion built in (no Calibre needed).
- Removing books, with an automatic database backup first.
- Covers for books bought from the Kobo Store, search, and sorting.
- Eject button that cleans up the `._` files macOS leaves behind.
